# Dataset Manifest: D-04 Pune Hourly Air Quality Reports

| Field | Detail |
|---|---|
| **Dataset ID** | D-04 |
| **Dataset Name** | Pune Hourly Air Quality Reports |
| **Source URL** | https://data.opencity.in/dataset/pune-hourly-air-quality-reports |
| **Access Date** | 2026-09-19 |
| **License / Terms** | Open Data Commons Open Database License (ODbL) / OpenCity terms |
| **Geographic Coverage** | Pune municipal stations (e.g., Shivajinagar, Karve Road, Katraj) |
| **Temporal Coverage** | Multi-year hourly monitoring records |
| **Sampling Frequency** | Hourly observations |
| **Fields & Units** | Timestamp, PM2.5 ($\mu g/m^3$), PM10 ($\mu g/m^3$), NO2, SO2, CO, Ozone, overall AQI score |
| **Locality Classification** | **REGIONAL_CONTEXT** |
| **Intended Use** | Environmental baseline context, threshold rule triggering, background correlation features |
| **Prohibited Claims** | Readings from distant municipal air stations must not be claimed as hyperlocal Viman Nagar Chowk corridor street-level sensor readings. |
| **Known Limitations** | Station sensors are sparse and subject to regional weather/topographical variation. Hyperlocal corridor vehicular pollution may differ. |
| **Privacy / Sensitivity** | Public environmental data; contains no personal data. |
