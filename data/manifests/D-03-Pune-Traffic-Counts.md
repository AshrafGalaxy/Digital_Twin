# Dataset Manifest: D-03 Pune Heterogeneous Traffic Count Dataset

| Field | Detail |
|---|---|
| **Dataset ID** | D-03 |
| **Dataset Name** | Heterogeneous Traffic Count Dataset from Signalized Intersections in Pune |
| **Source URL** | https://data.mendeley.com/datasets/xnf2k6n288/1 |
| **Access Date** | 2026-09-19 |
| **License / Terms** | Creative Commons Attribution 4.0 International (CC BY 4.0) |
| **Geographic Coverage** | Pune, Maharashtra (specifically Alankar Chowk, Jehangir Chowk, and RTO Chowk) |
| **Temporal Coverage** | Multi-day traffic survey recordings |
| **Sampling Frequency** | Classified directional counts aggregated across 5-minute / 15-minute bins |
| **Fields & Units** | Timestamp, intersection name, vehicle classification (2-wheelers, 3-wheelers, cars, buses, LCV, HCV), directional movement counts |
| **Locality Classification** | **PUNE_NON_LOCAL** |
| **Intended Use** | Feature engineering pipeline prototyping, time-of-day traffic distribution baselines, replay stream demonstration |
| **Prohibited Claims** | **MANDATORY:** Must NEVER be claimed as Viman Nagar Chowk observations. Must not claim that model evaluation on this dataset establishes local accuracy for the Viman Nagar corridor. |
| **Known Limitations** | Recorded at different Pune intersections with different geometry, capacity, and traffic generators. Short observation duration. |
| **Privacy / Sensitivity** | Aggregated vehicle counts; contains no video, face, or license plate data. |
