# Team Code of Conduct & Working Agreement

## 1. Project Context

This **Digital Twin** is an academic engineering capstone project developed collaboratively by a 5-member team of college classmates. Because our team is small and works closely together, our collaboration is founded on mutual trust, direct communication, and shared learning.

---

## 2. Our Team Standards

As classmates and collaborators, we commit to:
- **Mutual Respect & Kindness:** Treat each other with respect, value differing viewpoints, and support one another when tackling difficult technical challenges.
- **Open Communication:** Discuss ideas freely, ask questions when something is unclear, and provide positive, constructive peer feedback during code reviews.
- **Shared Responsibility:** Take pride in our shared codebase. If a build breaks or an issue arises, we work together to diagnose and resolve it.
- **Academic & Engineering Integrity:** Be honest about data sources, adhere to project architectural invariants (such as state separation and data provenance), and never falsify model metrics or test results.
- **Continuous Learning:** Foster an environment where everyone can learn new technologies (FastAPI, React, Deck.gl, SUMO, XGBoost) at their own pace without judgment.

---

## 3. Resolving Differences

If any disagreements arise—whether regarding architectural decisions, task distribution, or implementation details—we resolve them through:
1. Open discussion during team syncs or on GitHub discussions.
2. Grounding decisions in project specifications, technical benchmarks, and architectural invariants.
3. Consensus and shared understanding as classmates working toward a successful joint project.
